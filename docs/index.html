Présentation du projet

Ce projet démontre ma capacité à concevoir, déployer et documenter une stack de monitoring complète utilisée quotidiennement par les équipes SRE et SysAdmin. L’objectif est de fournir une base solide, reproductible et sécurisable, idéale pour un environnement de démonstration ou un premier déploiement.

Prometheus

Collecte des métriques, stockage TSDB, évaluation des règles d’alerting et self-monitoring.

Grafana

Visualisation, dashboards provisionnés automatiquement, interface d’exploration PromQL.

Node Exporter

Métriques système de l’hôte : CPU, mémoire, disque, réseau, load average…

cAdvisor

Métriques détaillées des conteneurs Docker (CPU, mémoire, I/O par container).

Démarrage en 3 commandes

git clone https://github.com/w7zk0/prometheus-grafana-portfolio.git

cd prometheus-grafana-portfolio

docker compose up -d

Grafana → http://localhost:3000 (admin / PortfolioAdmin2024!)

Prometheus → http://localhost:9090
